# Drift Ledger Privacy Policy

Last updated: August 10, 2026

Drift Ledger processes browsing activity locally to show active time, session summaries, and attention-drift indicators in Brave Desktop.

## Data Processed

Drift Ledger stores domain names, active-time totals, navigation counts, session summaries, category assignments, notification state, and user-configured settings. An optional historical import may add estimated domain-level aggregates from a Brave History database.

## Data Not Collected

Drift Ledger does not store full URLs, page content, page titles, search queries, form inputs, passwords, cookies, or incognito activity.

## Data Sharing

Drift Ledger does not transmit, sell, share, or synchronize user data. The extension contains no analytics, advertising, accounts, or remote API calls.

Drift Ledger uses browsing activity only to provide its user-facing time ledger, browsing-block summaries, and attention-drift indicators. This use complies with the Chrome Web Store User Data Policy, including its Limited Use requirements.

## Storage And Control

Data is stored in Brave's local extension storage on the user's device and retained for 30 days by default. Users can change the retention period, export a local JSON summary, remove an imported historical baseline, pause tracking, or clear all stored data from the options page.

## Permissions

The extension uses browser permissions for active-tab metadata, navigation events, idle state, local storage, periodic checks, toolbar status, and local notifications. It does not inject scripts into visited pages or request permission to read or modify page content.

## Contact

Support and privacy questions may be submitted through the public GitHub repository's issue tracker.
